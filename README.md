## 🚀 Featured Projects

### 🔍 [DeepTrust](https://deeptrust-nine.vercel.app) — AI Image Analysis

An AI-assisted image-analysis platform designed to help users examine whether an image may be AI-generated or manipulated. The interface presents a prediction alongside confidence information and analysis signals.

**Focus:** Next.js · JavaScript · Tailwind CSS · AI integration · Deployment

### 💧 [AquaSentinel](https://github.com/akshatinnovate-png/AquaSentiel) — Water Monitoring Prototype

A water-monitoring concept combining a software dashboard, simulated sensor readings, alert workflows, and a planned AWS-backed architecture. The current prototype is focused on demonstrating the software workflow before real-hardware deployment.

**Focus:** AWS architecture · IoT concepts · Simulation · Monitoring · Trend analysis

### 💸 [Fin Autopilot](https://github.com/utkarshsahay2008-cloud/Fin-Autopilot-final) — Financial Management Prototype
